# @octopusdeploy/openfeature-core

Internal shared logic for the Octopus Deploy OpenFeature providers.

**Don't install this package directly.** It has no public API and can change in any release without notice. Install a provider instead, and it brings in the matching version of this package for you:

- [`@octopusdeploy/openfeature`](https://www.npmjs.com/package/@octopusdeploy/openfeature) for web clients
